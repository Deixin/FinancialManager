# Proveniência da entrega v1.0

O [manifesto](source-manifest.json) registra os 24 arquivos recebidos, seus caminhos originais, os destinos e o SHA-256 calculado antes da organização. Os arquivos foram movidos sem alteração de conteúdo.

Os hashes descrevem os bytes da entrega original. A normalização de finais de linha pelo Git e edições futuras podem alterar o hash de arquivos textuais em um checkout.

Os dois templates preservados nesta pasta são referências históricas. As instruções ativas estão no [AGENTS.md](../../../AGENTS.md) e o índice ativo está em [docs/00-index.md](../../00-index.md).
