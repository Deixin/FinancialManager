# Infraestrutura cloud de referência

A arquitetura usa AWS São Paulo como referência, com adaptadores que preservam as fronteiras do domínio. A seleção e configuração concreta de serviços serão registradas nas histórias e ADRs correspondentes.

Não há infraestrutura como código ou deploy configurado no bootstrap. Nunca versione credenciais, estado sensível ou dados financeiros.
