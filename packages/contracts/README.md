# contracts

Estado: módulo TypeScript vazio do bootstrap; nenhuma funcionalidade ou integração de framework implementada.

Referência: [arquitetura](../../docs/architecture/04-technical-architecture.md). Execute pnpm --filter @financial-manager/contracts typecheck ou build para verificar o módulo isoladamente.
