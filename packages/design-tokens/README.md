# design-tokens

Tokens visuais compartilhados entre plataformas, sem componentes DOM ou dependência de runtime nativo.

Versão interna 0.1.0: tokens imutáveis, variáveis CSS derivadas e contrato puro de apresentação para shells. Sem React, Node, DOM ou I/O. [Uso e limites da US-016](../../docs/development/design-system.md), [ADR-0029](../../docs/architecture/adr/0029-design-tokens-e-shells.md).

Referência: [arquitetura](../../docs/architecture/04-technical-architecture.md). Execute pnpm --filter @financial-manager/design-tokens typecheck ou build para verificar o módulo isoladamente.
